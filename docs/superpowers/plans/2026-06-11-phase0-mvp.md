# OpenSteps Phase 0 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Phase 0 MVP — an MCP stdio proxy that emits signed, hash-chained receipts for every tool call, a YAML policy engine with allow/deny/approve, a standalone `opensteps verify` CLI, and the scripted prompt-injection launch demo.

**Architecture:** A raw newline-delimited JSON-RPC passthrough proxy (framework-agnostic, intercepts only `tools/call`); receipts canonicalized with RFC 8785 (JCS), signed with Ed25519, appended to JSONL; an offline verifier that recomputes every signature and chain link. The v1.0 hosted gateway moves to `legacy/`.

**Tech Stack:** Python 3.12, `cryptography` (Ed25519), `rfc8785` (JCS), `PyYAML`; `mcp` SDK only for the demo/tests extra; pytest + pytest-asyncio.

**Spec:** `docs/superpowers/specs/2026-06-11-phase0-mvp-design.md` — the receipt format, policy semantics, and CLI contract there are normative.

### Task 2: canonical.py + keys.py (TDD)

- [ ] Tests first (`tests/test_canonical.py`): `canonical_bytes({"b":1,"a":2}) == b'{"a":2,"b":1}'`; unicode + number formatting per JCS (`1.0` -> `1`? rfc8785 follows ECMAScript: `rfc8785.dumps({"x": 10.0}) == b'{"x":10}'`); `hash_json` equals `hashlib.sha256(canonical_bytes(...)).hexdigest()`; stable across key order.
- [ ] Implement:

```python
# src/opensteps/canonical.py
import hashlib
import rfc8785

def canonical_bytes(obj) -> bytes:
    return rfc8785.dumps(obj)

def sha256_hex(data: bytes) -> str:
    return hashlib.sha256(data).hexdigest()

def hash_json(obj) -> str:
    return sha256_hex(canonical_bytes(obj))
```

### Task 4: verify.py (TDD — the tamper matrix is the product claim)

- [ ] Tests: valid 3-receipt chain -> `valid=True, receipts_checked=3`; then each tamper fails at the right index with the right reason:
  - edit `policy.decision` of receipt 1 -> `signature` failure at index 1
  - delete middle receipt -> `prev_hash` mismatch at (new) index 1
  - reorder receipts -> failure at first out-of-link index
  - re-sign a forged receipt with a *different* key -> signature failure
  - garbage line / missing field -> structural failure with index
  - wrong public key -> failure at index 0
  - single-receipt mode verifies signature only
- [ ] Implement `verify_chain(path, public_key) -> VerificationResult(valid, receipts_checked, error_index, error_receipt_id, error_reason)` and `verify_receipt(receipt, public_key) -> (bool, reason)`. ### Task 7: proxy.py + e2e (the core)

Behavior contract:
- Spawn wrapped server `asyncio.create_subprocess_exec(*cmd, stdin=PIPE, stdout=PIPE, stderr=None)` (stderr inherits -> visible).
- Pump client stdin -> child stdin and child stdout -> client stdout, line by line; non-JSON or batch lines forwarded verbatim.
- Intercept client requests with `method == "tools/call"` and an `id`:
  - `request_hash = hash_json(msg["params"])`; tool name `params["name"]`; args `params.get("arguments", {})`.
  - policy `deny` -> do NOT forward; append receipt (`response_hash=None`); reply `{"jsonrpc":"2.0","id":id,"result":{"content":[{"type":"text","text":"OpenSteps: blocked by policy rule '<rule_id>'"}],"isError":true}}`.
  - `approve` -> `await asyncio.to_thread(approval_fn, ...)`; rejected -> as deny but `approver{id,method,decision:"rejected"}` recorded, message "rejected by approver"; approved -> forward and track pending with approver info.
  - `allow` -> forward, track `pending[id] = PendingCall(request_hash, tool, rule_id, decision, approver...)`.
- Child responses whose `id` is in pending: `response_hash = hash_json(resp["result"])` if `"result" in resp` else `hash_json(resp["error"])`; append receipt; forward.
- Receipt appends serialized with an `asyncio.Lock`. Client EOF -> terminate child, exit child's returncode.
